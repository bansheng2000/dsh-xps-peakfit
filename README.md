# dsh-xps-peakfit

XPS 分峰拟合 SOP —— 一个给 AI agent 用的 skill（Agent Skills 目录形态）。

固定四步，顺序不可变：

1. 荷电校正
2. 全谱分析
3. 高分辨分峰
4. 峰位移分析

每步带**通过门槛**与**产物契约**；每条结论必须带依据（`claim` / `依据` / `置信状态` / `备选解释`），缺依据自动降级为「不足以判定」。软件侧映射到 XPSPeak 4.1 的面板操作；交付物包含 XPSPeak 保存文件（`.xps` / `.rpa`）与 Origin 工程文件。

## 文件

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 技能正文：用途与边界、铁律、触发与使用方式、整体输入/输出要求、四个步骤（输入 / 处理目标 / 输出 / 注意事项 / 门槛）、产物契约与交付物清单、项目记录与续接、待确认问题、结论字段规范、禁止事项 |
| `references/deliverable-templates.md` | 四步产物 + 运行记录的可直接填空骨架 |

## 使用

把本仓库目录放进 agent 的技能目录即可（例如 DSH 的 `~/.agents/skills/dsh-xps-peakfit/`）。

触发词：XPS 分峰 / XPS 拟合 / XPS peak fitting / XPSPeak / XPSPEAK41 / 荷电校正 / charge correction / 高分辨谱 / C 1s 校正 / 峰位移。

## 边界（本 skill 不做什么）

- 不做仪器校准；不给全谱定量结论；不保证化学态归属正确
- 不解析各家仪器的数据格式；不内置拟合算法与软件依赖
- 不提供参考峰标准值库
- 判据阈值（校正容许漂移、拟合优度达标线等）一律由用户给定，缺失时标注「未核定」，不代为编造

## 硬约束

- 四个步骤的名称、数量与顺序是硬约束：不得新增、删除、重命名或打乱。
- 成品图默认不画残差子图；但残差判定（拟合优度 + 是否含系统性结构 + 判定依据）必须写进产物，缺少即视为未交付。
- 待确认项在 `SKILL.md` 第八节表化列出，并标注「阻塞 / 可延后」。
